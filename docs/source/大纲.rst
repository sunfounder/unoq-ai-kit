UNO Q AIoT学习套件课程大纲
=======================================

本课程基于 Arduino UNO Q 与 Arduino App Lab 平台设计，通过硬件实验、物联网应用和 AI 技术实践，逐步引导学习者掌握 电子控制、设备交互、云端连接以及智能设备开发。
课程共分为六个模块，由浅入深完成从 基础硬件控制 → IoT系统开发 → 多媒体交互 → Edge AI视觉 → AI大语言模型 → 综合AI项目 的学习路径。

模块A：基础交互（13课）
模块主题：探索 Arduino App Lab 与基础硬件控制
通过 LED、传感器和执行器实验，学习 Arduino 开发的基础知识，包括 数字输入输出、模拟信号处理、PWM 控制以及硬件交互。

课程设计原则：每课最多引入一个真正的新概念，其他都建立在之前学过的知识上。学生每一步都感觉"这我会，就多了一点点新东西"。

课程内容

1. Hello LED
   控制外接 LED 周期闪烁。学习面包板接线、LED 极性、电阻限流、数字输出（pinMode/digitalWrite/delay），以及 setup/loop 程序结构。

2. Button LED
   使用按键实现 LED 开关控制。学习数字输入（INPUT_PULLUP）、digitalRead、条件判断（if/else），以及上拉电阻的概念。

3. Tilt Alarm
   使用倾斜开关与有源蜂鸣器实现防倒提醒。巩固数字输入输出，引入新的输出器件（蜂鸣器），学习简单的去抖动技巧。

4. Potentiometer LED
   使用电位器调节 LED 亮度。引入模拟输入（analogRead）和 PWM 输出（analogWrite），理解模拟信号与数字信号的区别。

5. RGB LED
   使用三个电位器（或一个电位器切换）调节 RGB LED 颜色。在已掌握 PWM 的基础上，引入 RGB 颜色混合和三路 PWM 控制。

6. Photoresistor Night Light
   根据环境光强自动控制 LED。引入光敏电阻（模拟传感器），学习阈值判断和自动控制逻辑。

7. DHT11 Temperature & Humidity
   使用 DHT11 读取温湿度数据并显示在串口监视器。引入库的安装与使用、串口通信（Serial）的基础。

8. Ultrasonic Radar
   使用超声波模块测量距离并根据距离发出不同频率的提示音。引入时序传感器的工作原理，学习 pulseIn 和距离计算。

9. Thermistor Fan
   根据温度变化自动调节电机转速。引入热敏电阻（模拟温度传感器）和直流电机控制（NPN 三极管开关），综合模拟输入+PWM 输出。

10. Joystick LED
    使用摇杆控制 LED 亮度或 RGB 颜色。将摇杆理解为两个电位器的组合（双轴模拟输入），学习映射函数 map()。

11. Servo Pan-Tilt
    使用摇杆或旋钮控制舵机角度。引入舵机库（Servo），学习角度控制和新执行器类型。

12. IMU Attitude Detection
    使用 10 轴 IMU 模块检测设备姿态变化。引入 I2C 通信协议和复杂传感器库的使用。

13. Arduino IDE Comparison
    介绍 Arduino IDE 的使用，对比 App Lab 与传统 Arduino 开发方式的差异。

学习成果
完成本模块后，学习者可以：
● 独立完成基础硬件接线与调试
● 掌握 Arduino App Lab 的基本开发流程
● 使用常见传感器与执行器构建简单电子系统
● 理解数字信号、模拟信号、PWM 的区别和应用场景

模块B：多媒体交互（6课）
--------------------------

模块主题：使用 AVIO Carrier 的麦克风和喇叭，实现语音识别（STT）、语音合成（TTS）以及语音控制硬件。

本模块无需面包板接线——所有硬件（麦克风、喇叭、按键）都在 Carrier 上。

Lesson 1：Camera Basics

目标：认识 CSI 摄像头。

内容：Camera Brick、实时画面、Image Stream、Vision Pipeline。

最后：在 Web UI 显示摄像头画面。

Lesson 2：Local TTS

目标：让喇叭播放声音。

内容：Web UI 输入文字 → 点击按钮 → 喇叭朗读。学习 EdgeTTS 初始化和语音合成。

Lesson 3：File TTS

目标：导入文本文件 → 喇叭朗读。

内容：上传 .txt 文件 → TTS 整篇朗读。学习文件读取和长文本分段播放。

Lesson 4：Local STT（已完成）

目标：听到的语音，用文字打印出来。

内容：自动录音 → 本地 Whisper STT → print("You said: ...")。学习语音转文字。

文档和README.md需要提示第一次会报这个错

Lesson 5：Robot Shield Button + Local STT

新增一个知识点：事件驱动。

USR 按下 → 开始录音；USR 松开 → 停止录音 → 本地 STT → "You said: ..."

学生开始接触事件驱动编程。

Lesson 6：Voice Command

新增一个知识点：语音控制硬件。

Speech → Text → if text == "red": RGB = Red

说 "Red" 亮红灯，"Yellow" 亮黄灯，"Green" 亮绿灯。学习 STT → 关键词匹配 → Bridge 的完整链路。

Lesson 7：STT + TTS Combined

新增一个知识点：语音指令 + 语音反馈闭环。

Speech → STT → if "turn left" → Servo left + TTS "OK, turning left"

说 "Turn left" → 云台左转 + 喇叭回复。学习 STT → 动作执行 → TTS 反馈的完整闭环。

学习成果：掌握 STT（语音转文字）和 TTS（文字转语音）；理解事件驱动编程模式；实现语音到硬件的完整控制链路。
